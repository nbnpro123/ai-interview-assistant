# AI Interview Assistant

Помощник для прохождения собеседований в реальном времени. Слушает вопрос через системный аудиопоток (WASAPI Loopback), распознаёт речь (Google STT), отправляет в DeepSeek API и показывает готовый ответ.

## Возможности

- **Автораспознавание** — VAD определяет речь и автоматически отправляет в AI по окончании паузы
- **Ручной захват** — кнопка для точного выделения фрагмента вопроса
- **Ручной ввод** — можно напечатать вопрос вручную
- **История ответов** — все Q&A накапливаются с цветной маркировкой источника
- **Режим скрытия** — окно прячется в трей (Ctrl+H), не видно при демонстрации экрана
- **Беззвучный режим** — отключает звуковые уведомления
- **Настройки** — API ключ, модель, системный промпт, устройство захвата

## Установка

```bash
git clone https://github.com/nbnpro123/ai-interview-assistant.git
cd ai-interview-assistant
pip install -r requirements.txt
```

## Настройка

1. Скопируйте `config.example.json` в `config.json`
2. Вставьте ваш API-ключ DeepSeek в поле `api_key`
3. При необходимости отредактируйте `system_prompt` под свою легенду

## Запуск

```bash
python main.py
```

## Использование

| Кнопка | Действие |
|--------|----------|
| 🎤 Начать прослушивание | Запуск авто-захвата системного аудио |
| ⏺ Захват | Ручная запись фрагмента (нажать/отжать) |
| ✏️ + 📤 Отправить | Набрать вопрос вручную |
| 🔇 Без звука | Отключить звук уведомлений |
| 🕶 Скрыть (Ctrl+H) | Спрятать окно в трей |
| 🗑 Очистить | Сбросить историю |
